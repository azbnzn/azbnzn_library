# 🚀 AtCoder Parallel Stress Tester (並列ストレステスター)

マルチコアCPUの能力を限界まで引き出し、**数十〜数百ケース/秒**の超高速でランダムストレステストを実行する競技プログラミング専用ツールです。

---

## ⚡️ 高速化の仕組み（なぜ速いのか？）

### 1. マルチコア並列ワーカ (Multi-Core Worker Pool)
- 従来のシングルスレッド実行（1ケースずつ順次実行）とは異なり、お使いの Mac の **10コア CPU** をフル活用して並列実行します。
- 1,000ケースのテストであれば、シングルスレッドで数十秒かかる処理が、**数秒〜十数秒**で一瞬で完了します。

### 2. パイプによるインメモリ高速 I/O (Pipe-based In-Memory I/O)
- 毎回ディスクに `input.txt` や一時出力ファイルを書き出す従来方式を廃止。
- Generator の標準出力を直接 Naive と Solver の標準入力パイプへインメモリ転送するため、ディスクI/Oのボトルネックがゼロです。

---

## 🌟 主な機能

### 1. リアルタイム・スピードメーター & 進捗ダッシュボード
- **速度計測 (cases/sec)**: 1秒間に何ケース処理できているかをリアルタイム表示。
- **Server-Sent Events (SSE)**: ポーリングなしで毎秒10回以上の滑らかな進捗バー更新。
- **AC / WA / RE / TLE 内訳カウント**: テスト全体の健全性を一目で把握。

### 2. 最小反例ケース探索 (Smallest Counterexample Reduction)
- ランダムテストでバグが見つかった際、**「最も入力サイズが小さく、デバッグしやすい最小ケース」** を自動探索・強調表示（🏆 マーク）。
- $N=100$ の巨大ケースを追う苦労から解放され、$N=2$ や $N=3$ などの最小ケースで即座に原因を解明できます。

### 3. `tools/stress_test/` 既存ファイルとの双方向同期
- 画面上部の **「📂 tools/ から読込」** ボタンを押すだけで、現在リポジトリ内にある `tools/stress_test/main.cpp`, `naive.cpp`, `generator.cpp` を1発でエディタに取り込めます。
- Web上で修正したコードを **「💾 tools/ へ保存」** でそのまま書き戻すことも可能です。

### 4. `cp_debugger` (デバッガ) へのワンクリック転送連携
- 失敗したテストケースを選択し、**「⚡️ CP Debugger でバグ行特定」** ボタンを押すと、コードと該当の入力・正解出力がそのままデバッガへ転送され、即座にバグ行番号と原因の診断が始まります。

## 🖥️ 起動方法

### 統合ランチャーから起動（推奨）
リポジトリルートで以下のコマンドを実行します：

```bash
# 短縮エイリアスで直接起動
python3 app/run.py stress

# または
python3 app/run.py st
```

### 直接起動
```bash
python3 app/stress_tester/server.py
```
起動すると自動的にブラウザで `http://127.0.0.1:8085` が開きます。

---

## ⌨️ 操作方法 & ショートカット

| 操作 | 動作 |
|---|---|
| `Ctrl + Enter` / `Cmd + Enter` | 並列ストレステストの開始 |
| スライダー操作 | 並列実行ワーカ数（スレッド数）のリアルタイム調整 (1〜16) |
| 失敗ケース行クリック | 入力データ・期待値・実際出力の詳細 Diff 表示 |
| サンプル読込 | 区間和バグ、MOD計算負数余りバグ、無限ループバグの再現コードを即座にロード |
