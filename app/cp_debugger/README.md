# AtCoder CP Debugger (競技プログラミング デバッガ)

C++ で書かれた競技プログラミングのコードに対し、**「バグが発生している行」とその「原因」を自動特定**し、**ストレステスト**および**変数トレース可視化 (icecream / cerr)** を提供するローカル完結型デバッグツールです。

---

## 🚀 主な機能

### 1. バグの行と原因の特定 (Bug Line & Cause Identification)
- **バグ発生行の自動ピンポイント特定**:
  - エラー発生時、コードエディタ上の該当行に赤色ハイライトと警告バッジが自動付与されます。
  - 「バグ行へジャンプ」ボタンで即座に該当箇所へスクロールします。
- **人間可読な日本語での原因・アドバイス解説**:
  - **配列外参照 (Heap/Container/Stack Buffer Overflow)**: `vector` のサイズ外アクセスや 1-indexed / 0-indexed のズレを検出。
  - **0除算 (Division by Zero)**: `x / 0` や未初期化変数による除算を検出。
  - **符号付き整数オーバーフロー (Integer Overflow)**: `int` (32bit) の限界超過を検出し、`long long` への変更を助言。
  - **不正ビットシフト (Invalid Bit Shift)**: `1 << 40` (1LL 忘れ) や負のシフトを検出。
  - **ヌルポインタ参照 / セグフォ (SIGSEGV)**: 木・グラフの未初期化ポインタアクセスを検出。
  - **アサーション違反 (Assertion Failure)**: `assert(cond)` の失敗条件を明示。
  - **無限ループ / TLE 行特定 (Watchdog Timer Profiling)**: 単に「タイムアウト」と出すだけでなく、内部プロファイラが **無限ループで回り続けている行番号や関数をピンポイントで特定** してエディタ上に赤色ハイライト表示。
  - **出力不一致 (WA)**: 期待される出力と実際の出力をトークン単位・行単位で比較し、最初の不一致トークンと Diff を表示。

---

### 2. ストレステスト (Stress Test Studio)
- **3つのコードを同時検証**:
  1. `Solver (main.cpp)`: 検証したい解法
  2. `Naive (naive.cpp)`: 正解が保証された愚直解法 ($O(N^2)$ や $O(2^N)$ など)
  3. `Generator (gen.cpp)`: ランダム入力を標準出力に生成するプログラム (`std::mt19937` 等)
- **ワンクリック連続実行**:
  - 指定回数（30回、50回、100回、300回など）を高速に自動実行。
  - 不一致 (WA) または実行時エラー (RE/TLE) が発生した瞬間に即座に停止。
- **⚡️「このケースをデバッガで開いて診断」連携**:
  - 失敗した入力・期待される正解出力をワンクリックで「単一ケース デバッガ」へ自動転送。
  - 即座にバグ行と原因の診断が走るため、**「ストレステストで落とし、そのまま1秒でバグ行を直す」** という理想的な競技フローが実現します。

---

### 3. 自動 cerr / icecream 埋め込み & トレース可視化 (Trace Timeline)
- **`icecream-cpp` 完全対応**:
  - `include/mylib/icecream.hpp` がプロジェクトに組み込まれており、`IC(x, y)` で途中経過を簡単に出力可能。
  - 「🍦 ic 挿入」ボタンを押すだけで、必要なヘッダーとコンテキスト設定（行番号・関数名表示）が自動挿入されます。
- **構造化タイムライン & 行ジャンプ**:
  - `stderr` に出力されたトレースを自動解析し、`Step`、`Line`、`関数名`、`変数名: 値` のテーブルとして整理。
  - テーブルの行をクリックすると、コードエディタ上の該当行へジャンプします。
  - 変数名（例: `dp`, `ans`）によるリアルタイム絞り込み検索が可能。
- **異常値警告 (Anomaly Detection)**:
  - `18446744073709551615` (size_t -1 やアンダーフロー)、`NaN`、`Inf`、極端な負の値などを自動検知してアラート表示。

## 🖥️ 起動方法

### 統合ランチャーから起動（推奨）
リポジトリのルートで以下のコマンドを実行します：

```bash
# 短縮エイリアスで直接起動
python3 app/run.py debug

# または
python3 app/run.py cpd
```

または番号選択メニューから：
```bash
python3 app/run.py
# メニューから cp_debugger を選択
```

### 直接起動
```bash
python3 app/cp_debugger/server.py
```
起動すると、ブラウザが自動的に開き `http://127.0.0.1:8080` (または利用可能なポート) に接続されます。
終了するにはターミナルで `Ctrl + C` を押してください。

---

## ⌨️ キーボードショートカット & 操作ヒント

| 操作 | 動作 |
|---|---|
| `Ctrl + Enter` / `Cmd + Enter` | コードを実行してバグ解析を開始 |
| `Tab` | 4スペースのインデント挿入 |
| 行番号クリック | エディタ上の該当行へジャンプ |
| ファイルをドラッグ＆ドロップ | `.cpp` ファイルをエディタに直接読み込み |
| サンプル選択 | 配列外参照・0除算・オーバーフロー等の再現コードを瞬時にロード |
