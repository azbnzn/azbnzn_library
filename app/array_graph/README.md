# Array Graph (配列・数列グラフプロッター)

競技プログラミングにおける数列・配列問題（累積和、株価変動DP、傾き変化・傾きトリック、三分探索の凸関数チェック、ヒストグラムなど）を手元で素早くプロット・可視化・考察するためのツールです。

---

## 🌟 主な機能

### 1. 📥 配列の自動プロット
以下の形式の入力データをテキストエリアに貼り付けるか、テストケースファイルをドラッグ＆ドロップするだけで即座にグラフを描画します：

```text
N
A_1 A_2 ... A_N
```

- $N$: 配列の要素数
- $A_i$: 整数（正数、0、負数すべて対応）
- ※ $N$ の行を省略して数値のみを貼り付けた場合や、改行区切り・カンマ区切りの数列も自動認識します。

---

### 2. 📐 ボトム $y=0$ の自動最適化（仕様準拠）
- **要素が全て非負（$A_i \ge 0$）の場合**:
  - Y軸の下限（ボトム）を **自動的に $y=0$ に固定** して出力します。
  - これにより、ヒストグラムや非負のコスト関数、累積和などが地面（$y=0$）から立ち上がる自然なスケールで視覚的に把握できます。
- **負の要素（$A_i < 0$）が含まれる場合**:
  - 最小値 $\min(A)$ を綺麗に収めるようY軸下限が拡張され、基準線となる **$y=0$ の軸ラインが赤色の強調線** で明瞭に描画されます。
- **Y軸モードの切り替え**:
  - 「非負時はボトム y=0 (仕様準拠)」
  - 「常に y=0 を含む」
  - 「min〜max 完全フィット」

---

### 3. 📏 縦横比（縮尺 1:1 等倍 & ユーザー変更対応）
- **デフォルトで縦横の縮尺 1:1（等倍）**:
  - X軸の1目盛りとY軸の1目盛りが画面上で **まったく同一のピクセル長** で描画されます。
  - グリッド線も綺麗な正方形になり、傾き 1 の直線は正確に 45 度として描画されるため、傾きトリックや幾何的考察が歪みなく正確に行えます。
  - 非負時はボトム $y=0$ を保ったまま、縦横比 1:1 で収まるよう最適配置されます。
- **ユーザーによる自由な変更**:
  - **1:1 (等倍)**: 正方形目盛り（デフォルト）
  - **自動フィット**: ウィンドウ領域いっぱいにX軸・Y軸を独立に拡大表示
  - **カスタム比率**: スライダー（0.2x 〜 5.0x）やプリセットボタン（0.5x, 1.0x, 2.0x）で縦横比を自由自在に伸縮調整可能

---

### 4. 📊 多彩なグラフ表現
- **点・散布図 (Scatter / デフォルト)**: 各点 $(i, A_i)$ を明瞭にプロットして表示。
- **折れ線グラフ (Line)**: 点同士を結び、面積を柔らかくグラデーション表示。推移の考察に最適。
- **棒グラフ (Bar)**: $y=0$ を基準とするヒストグラム表示。長方形最大化問題や水溜めシミュレーションに最適。
- **階段グラフ (Step)**: 区間ごとの定数関数・ステップ推移を表示。

---

### 5. 🔍 インタラクティブな操作と解析
- **マウスホバー & ツールチップ**:
  - 各点にカーソルを合わせると、インデックス $i$、値 $A_i$、直前との差分 $\Delta = A_i - A_{i-1}$、累積和 $\sum_{k=1}^i A_k$ をポップアップ表示。
  - クロスヘア（十字線）が座標軸までガイド。
- **パン（ドラッグ移動） & ズーム（ホイール回転）**:
  - アップクローズ感度を最適化し、細部を滑らかに拡大・探索可能。
- **1-indexed / 0-indexed 切り替え**:
  - 競プロで一般的な $1 \le i \le N$ と、プログラミング言語基準の $0 \le i < N$ をワンクリックでトグル。
- **累積和（Prefix Sum）の重ね合わせ表示**:
  - 元の数列と同時に累積和の推移をオレンジ色の破線で同時プロット。
- **基本統計情報 (Analytics)**:
  - 要素数 $N$、最小値 $\min(A)$ とそのインデックス、最大値 $\max(A)$ とそのインデックス、総和 $\sum A_i$、平均値をサイドバーに常時算出表示。

---

### 6. 💻 競プロ向けエクスポート
- **テキストコピー**: `N \n A_1 A_2 ... A_N` 形式でクリップボードにコピー。
- **C++ コード生成**: `vector<long long> a = { ... };` 形式で即コピー。
- **画像保存 (PNG)**: レポートや考察メモ、SNS共有用の高解像度 PNG 画像としてワンクリック保存。

---

### 7. 🗂️ サイドバーの折りたたみ & 状態自動保存 (画面分割対応)
- **ワンクリック開閉**: ヘッダーの「☰」やツールバーの「◀ パネルを隠す」、サイドバー上部の「◀ 閉じる」ボタンからいつでもサイドバーを折りたためます。
- **ショートカットキー**: **`Ctrl+B`** または **`Cmd+B`** で瞬時にトグル可能。
- **グラフ全幅表示**: サイドバーを折りたたむと、キャンバスが自動的に画面幅いっぱいに拡大され、画面分割（スプリットビュー）時でも大きなグラフで快適に考察できます。
- **状態の自動保存**: 開閉状態は `localStorage` に保存されるため、ページをリロードしても閉じた状態がそのまま維持されます。

---

## 🚀 起動方法

### 方法 A: アプリランチャーから起動（推奨）
```bash
python3 app/run.py graph
# または
python3 app/run.py array
```

### 方法 B: ブラウザで直接開く
```bash
open app/array_graph/index.html
```
