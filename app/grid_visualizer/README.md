# Grid Visualizer (グリッド考察ボード)

競技プログラミングのグリッド問題（迷路最短経路、壁破壊、2次元累積和、シミュレーション、盤面考察など）を手元で素早く可視化・シミュレーションするための補助ツールです。

---

## 🌟 主な機能

### 1. 📥 テキスト / ファイル読み込みモード (文字列モード & 数字モード)
ヘッダーの **「📥 テキスト・ファイル読込」** ボタンから、AtCoderの入力データをそのまま貼り付けるか、ファイル（`.txt`, `.in` 等）をドラッグ＆ドロップして即座に盤面を構築できます。

- **🔤 文字列モード (String Mode)**:
  - **入力形式**:
    ```text
    H W
    S_1
    S_2
    ...
    S_H
    ```
  - **表示ルール**: 文字が `#` のマスのみ自動的に**黒色（壁マス）**で塗りつぶし、道（`.`）は白マスとして表示します。
  - `S`, `G` などの文字が含まれる場合は、マスの中にその文字が表示されます。
  - ※ 1行目の `H W` は省略して文字列のみを貼り付けることも可能です。

- **🔢 数字モード (Number Mode)**:
  - **入力形式**:
    ```text
    H W
    A_{1,1} A_{1,2} ... A_{1,W}
    A_{2,1} A_{2,2} ... A_{2,W}
    ...
    A_{H,1} A_{H,2} ... A_{H,W}
    ```
  - **表示ルール**: 空白区切りの数値を各マスの中にそのまま数値として表示します（2次元累積和、コスト付きグリッド、DPテーブルなどの考察に最適）。
  - ※ 1行目の `H W` は省略して数値行のみを貼り付けることも可能です。

- **ファイル読み込み対応**:
  - ドロップゾーンへのドラッグ＆ドロップ、またはファイル選択ダイアログからテストケースファイルを一括読込可能。
- **ワンクリック・サンプル投入**:
  - 「サンプル入力を試す」ボタンを押すだけで各モードの入力例を即座に試せます。

---

### 2. 🔄 ワンクリック色巡回（カラーサイクル）
- **初期状態は2色（白 ⇄ 黒）**: クリックするたびに白と黒が交互に切り替わります（迷路の道・壁作成に最適）。
- 毎回パレットから色を選び直す必要がなく、直感的にサクサク塗り分けられます。
- **塗り分け色数（$K$）の指定**:
  - 2色（デフォルト）: `白 ⇄ 黒`（迷路の道・壁問題に最適）
  - 3色: `白 → 黒 → 赤 → 白`（壁＋訪問済み・注目マスなど）
  - 4色以上: `白 → 黒 → 赤 → 青 → 緑 ...`
- **各色の自由カスタマイズ**: プレビュー内の色チップをクリックするとカラーピッカーで自由に変更可能。
- **ドラッグ連続塗り**: クリックして出た色のままマウスをなぞると、連続して同じ色を塗れます。
- **右クリックで逆戻し**: 押しすぎた場合は右クリックで前の色（黒→白）に逆順で戻せます。

---

### 3. ⌨️ 数字・文字のシームレス入力
- マスをクリックして選択し、キーボードでそのまま数字（`0`〜`9`）や文字（`INF`, `-1` など）をタイプ可能。
- **矢印キー (↑↓←→)**、**Tab**、**Enter** で隣のマスにキーボードだけで連続移動。
- **Backspace / Delete** でマスの内容をサッと消去。
- **自動コントラスト文字色**: 背景色が暗いときは白文字、明るいときは黒文字を自動調整。

---

### 4. 📐 グリッドサイズ ($H \times W$) の自由変更
- 行数 $H$ と列数 $W$ を指定して生成（最大 $50 \times 50$）。
- 「+行」「-行」「+列」「-列」ボタンで動的に拡大・縮小可能。

---

### 5. 💻 競プロ特化のエクスポート
- **盤面コピー**: 現在の盤面を AtCoder 形式テキスト（`H W` ヘッダー付き）としてクリップボードにコピー。数字が入っている場合は空白区切りの数列として自動出力。
- **C++ コード生成**:
  - 文字列グリッドの場合: `vector<string> s = { ... };`
  - 数値グリッドの場合: `vector<vector<int>> a = { ... };`

---

### 6. その他の便利機能
- **サイドバーの折りたたみ (画面分割・最大化対応)**: ヘッダーの「☰」やツールバーの「◀ パネルを隠す」、サイドバー上部の「◀ 閉じる」、またはショートカット **`Ctrl+B` / `Cmd+B`** でサイドバーを瞬時に折りたためます。画面を半分に分割して考察する際も、グリッド盤面だけを画面幅いっぱいに広げて作業できます（状態はブラウザに自動保存）。
- **0-indexed / 1-indexed 切り替え**: 座標ヘッダーの表示切り替え。
- **サイズスライダー**: マスの拡大・縮小（$28\text{px} \sim 72\text{px}$）。
- **Undo / Redo**: `Ctrl+Z` / `Cmd+Z`、`Ctrl+Y` / `Cmd+Y` 対応。
- **バケツ塗り・消しゴムモード**: 連結成分の塗りつぶしや白紙化。

---

## 🚀 起動方法

### 方法 A: アプリランチャーから起動（推奨）
```bash
python3 app/run.py grid
```

### 方法 B: ブラウザで直接開く
```bash
open app/grid_visualizer/index.html
```
