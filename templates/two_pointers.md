# 尺取り法 (Two Pointers)

区間の条件に単調性があるとき、左端 `l` と右端 `r` を単調に進めることで $O(N)$ で全区間を探索するテクニックです。  
`solve()` 内に直書きできる 3 つの基本パターン（左端固定・右端固定・最短区間）を用意しています。

---

## 1. 概要・パターンの使い分け
- **計算量**: $O(N)$（`set` 等を併用する場合は $O(N \log N)$）
- **3つのパターンの選び方**:
  1. **パターン 1（左端 `l` ループ・半開区間 `[l, r)`）**:
     - 「一瞬でも条件違反の状態に入ってはいけない」問題（例: 重複要素を絶対に入れられない、0除算が起きる等）で最も安全。
  2. **パターン 2（右端 `r` ループ・閉区間 `[l, r]`）**:
     - 「まず `a[r]` を追加し、条件違反している間 `l` を進めて削る」ができる問題に最適。`if (l == r)` の分岐が不要で最も短く書けます。
  3. **パターン 3（条件を満たす最短区間）**:
     - 「総和 $\ge K$ となる最小の長さ」などを求める場合に使います。

---

## 2. コピペ用コード (直書き)

### パターン 1: 左端 `l` 固定ループ（半開区間 `[l, r)` 基本形）
```cpp
ll r = 0;
ll sum = 0; // 区間 [l, r) の状態 (合計・種類数・setなど)
ll ans = 0;

rep(l, n) {
  // r を 1 つ進めても条件を満たす限り r を伸ばす
  while (r < n && sum + a[r] <= k) {
    sum += a[r];
    r++;
  }

  // この時点で [l, r) は l を左端とする極大な有効区間 (長さ r - l)
  ans += (r - l);       // 条件を満たす区間の個数を数える場合
  // chmax(ans, r - l); // 条件を満たす最長の区間長を求める場合

  // 次の l へ進むための後処理
  if (l == r) {
    r++; // 区間が空 [l, l) で 1 つも進めなかった場合は r も一緒に進める
  } else {
    sum -= a[l]; // a[l] を区間から外す
  }
}
```

### パターン 2: 右端 `r` 固定ループ（一旦追加して縮める形）
```cpp
ll l = 0;
ll sum = 0;
ll ans = 0;

rep(r, n) {
  sum += a[r]; // 右端 a[r] を追加

  // 条件に違反している間、左端 l を進めて要素を削る
  while (l <= r && sum > k) {
    sum -= a[l];
    l++;
  }

  // この時点で閉区間 [l, r] (長さ r - l + 1) は条件を満たす極大区間
  ans += (r - l + 1);       // 条件を満たす区間の個数
  // chmax(ans, r - l + 1); // 条件を満たす最大長
}
```

### パターン 3: 条件を満たす「最短」区間を求める形
```cpp
ll l = 0;
ll sum = 0;
ll ans = INF;

rep(r, n) {
  sum += a[r]; // 右端 a[r] を追加

  // 条件を満たしている間、記録を更新しつつ左端 l を詰める
  while (l <= r && sum >= k) {
    chmin(ans, r - l + 1);
    sum -= a[l];
    l++;
  }
}
// (ans が INF のままなら条件を満たす区間は存在しない)
```

---

## 3. 注意点
- **単調性の確認**:
  - 区間を広げたときに条件が「満たす $\to$ 満たさない」と単調に変化する必要があります（負の数が混ざると区間の和は単調でなくなるため尺取り法は使えません）。
- **`l == r` の追い越し防止（パターン1）**:
  - 1 要素だけで条件を満たさない（`a[l] > k`）とき、`r` が `l` に留まるため、`if (l == r) r++;` を忘れると次のループで `l > r` となりバグになります。
  - バグを完全に防ぎたい場合はライブラリ版 `#include <mylib/TwoPointers.hpp>` も利用可能です。
