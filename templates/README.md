# 競技プログラミング コピペ用テンプレート集 (Templates)

ライブラリ (`mylib`) として include するよりも、**提出コードに直接コピペして問題ごとにカスタマイズしながら使うのに適した**定石アルゴリズム・データ構造のテンプレート集です。

各アルゴリズムごとに、そのまま動くサンプル付きの `.cpp` ファイルと、使い方・注意点・コピペ枠をまとめた `.md` ファイルを用意しています。

## 使い方・設計方針

1. **コピペ専用ブロック**:
   - 各 `.cpp` ファイル内には `// ==================== [コピペここから] ====================` から `// ==================== [コピペここまで] ====================` が明記されており、その部分をコピーして提出コードに貼り付けるだけで使えます。
2. **単体実行可能**:
   - すべての `.cpp` ファイルは末尾に `main()` と動作確認用のテストコードを含んでいるため、そのままコンパイル・実行して挙動を確認できます。
3. **0-indexed 統一**:
   - 頂点番号や配列インデックスはすべて `0-indexed` で統一しています。
4. **ACL / mylib との互換性**:
   - AtCoder Library (`atcoder::fenwick_tree`, `atcoder::segtree` 等) や自作ライブラリと組み合わせて使いやすいように型定義・命名を行っています。
